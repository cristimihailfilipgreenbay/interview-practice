# Flask + Angular over Streamlit or Next.js

The assignment's brief names Streamlit or Next.js as the two supported front-end options
("we recommend Streamlit"), but this project builds with Flask (Python backend) and
Angular (TypeScript SPA) instead. The brief's own framing — "there are a number of ways we
can choose to develop our application; we recommend Streamlit" — treats that as a
recommendation, not a requirement, so this is a deliberate choice, not an oversight. Worth
confirming with the course instructor/JTL regardless, since it's a literal deviation from
the two options actually named.
